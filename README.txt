# Конструктор питания 🐾

Компактный калькулятор и библиотека рецептов для домашней части кормления.

## Открыть без установки

Скачайте [`calculator.html`](https://github.com/otravva-dog/dog-calculator/blob/main/calculator.html) кнопкой **Download raw file** и откройте в браузере. В него встроены Manrope, стили и логика. В автономном режиме рецепты хранятся на устройстве.

**PDF:** кнопка «PDF» → в диалоге печати выбрать «Сохранить как PDF». В документ входят собственные цветные SVG-иконки продуктов, граммовки на порцию и партию, КБЖУ и режимы приготовления.

## Запуск на gavstronomiya.ru / REG.RU

Нужен именно **веб-хостинг с PHP 8.1+ и PDO_SQLITE**, а не только регистрация домена. В REG.RU: «Мои услуги» → «Хостинг» → активная услуга → панель управления. Наличие купленного домена не означает наличие хостинга. PHP на тарифе Host-Lite может быть недоступен: [справка REG.RU](https://help.reg.ru/support/hosting/php-asp-net-i-skripty/kak-smenit-versiyu-php-na-hostinge).

1. Сделайте резервную копию действующего сайта.
2. В панели хостинга включите PHP 8.1 или новее и HTTPS. Проверьте расширение **pdo_sqlite**.
3. Скачайте проект через **Code → Download ZIP**. Распакуйте.
4. Скопируйте **содержимое** проекта в корневую папку нужного сайта (имя папки уточняется в панели). Нужны `index.html`, `styles.css`, `product-icons.js`, `script.js`, `fonts/`, `api/` целиком, включая `email-auth.php`. Не загружайте данные рабочих пользователей в GitHub.
5. Откройте `https://www.gavstronomiya.ru/`. При наличии серверного API появится кнопка **«Войти»**.
6. Настройте почту по [EMAIL-SETUP.md](EMAIL-SETUP.md). Зарегистрируйтесь: email и пароль от 12 символов. Подтвердите email по ссылке в письме. На другом устройстве войдите с тем же email и паролем.

Если в корне уже размещён другой сайт, установите калькулятор в отдельную папку, например `nutrition/`, сохранив структуру файлов. API определяется относительно папки калькулятора. Не заменяйте действующую главную страницу без необходимости.

В REG.RU нет автоматически подключённого доступа из этого чата. Изменение файлов в GitHub само по себе не размещает их на REG.RU, если у вас не настроено отдельное развёртывание. Эта версия подготовлена для установки, её размещение на домене пока не подтверждено.

## Серверные рецепты

- Сессии с защищёнными HttpOnly/SameSite cookies; запросы записи защищены CSRF-токеном и проверкой Origin.
- Сервер авторизует каждый рецепт по владельцу. Два устройства видят одну библиотеку после входа и синхронизации.
- В «Итоге» всегда доступно **«Сохранить новый рецепт»**: новый вариант создаётся независимо от открытого. Исходный рецепт не изменяется.
- Только после открытия записи из списка появляется отдельное **«Обновить открытый»**. Пока состав и название не изменены, эта кнопка неактивна.
- После сохранения нового варианта калькулятор остаётся независимым черновиком. Повторное нажатие для того же состава, граммов и названия не создаёт дубль.
- **«Новый расчёт»** очищает состав в «Итоге», сохраняя текущие цели и профиль собаки.
- Открытие рецепта и импорт не подменяют текущий профиль и цели старыми настройками. Кнопка PDF в списке печатает сохранённый рецепт, не загружая его в рабочий черновик.
- Кнопок над списком больше нет. JSON-резервная копия и импорт находятся в раскрывающемся разделе «Итога».
- Конфликт правок с двух устройств не перезаписывает свежую версию. Нажмите «Синхронизировать», откройте актуальный рецепт или сохраните новый рецепт. Даже после синхронизации старый открытый черновик не получает права перезаписать свежую версию: для обновления нужно заново открыть запись.
- Создание нового рецепта и изменения черновика не отправляются в облако до нажатия «Сохранить».
- Ранее локальные рецепты: откройте каждый и нажмите «Сохранить» после входа. JSON-экспорт — резервная копия, PDF — удобный документ, не формат импорта.
- До 500 рецептов на пользователя. Восстановление пароля — по скачанному коду; после восстановления прежние сессии отзываются. Код никому не передавайте.
- SQLite и PHP-сессии создаются в закрытой папке **выше корня сайта**, с запретом использования папки внутри DocumentRoot. Резервируйте эту папку отдельно от кода.
- По умолчанию приватная папка: родитель папки сайта + `nutrition-private-<хеш>`. Если ограничения хостинга не дают её создать, задайте `NUTRITION_DATA_DIR` в окружении PHP: существующий закрытый путь вне корня сайта с правами записи. Не помещайте базу в `public_html`, `www`, `htdocs` или GitHub.
- Не используйте один логин для разных людей. Не храните код восстановления в публичном репозитории. Срок сессии — до 30 дней, с выходом после 7 дней бездействия.

Непродуктовые эмодзи и значок компьютера у даты убраны.

- КБЖУ на 100 г редактируются отдельно от граммов. Калории не заменяются автоматически формулой 4/9/4.

## Энергия и полный КБЖУ в профиле

- FEDIAF по активности: k = 95 / 110 / 125 / 150 / 175 в зависимости от выбранной нагрузки. По умолчанию 110 для умеренной активности 1–3 ч/день без интенсивной нагрузки.
- FEDIAF по возрасту — альтернативная оценка: для 1–2 лет k=130, 3–7 лет k=110, старше 7 лет k=95. Для дробного возраста до 3 лет используется младшая взрослая группа. Возрастной и активностный коэффициенты не перемножаются.
- NRC / WSAVA: 95 для неактивной и 130 для активной взрослой собаки. Таблица WSAVA прямо ссылается на расчёты NRC 2006, это не третья независимая формула.
- MER = k × вес⁰·⁷⁵. При k=110 и 13,2 кг: **761,8 ккал/сутки**, округлённо 762. RER = 70 × вес⁰·⁷⁵ = **484,8 ккал**. RER означает расход в покое, а не отдельную норму сухого корма. Тип корма не меняет потребность собаки.
- Статус стерилизации и порода сохранены в профиле. Выбранные таблицы не задают для них отдельного множителя: дополнительный коэффициент не придумывается. Сезонная поправка применяется только вручную.
- БЖУ — ваши прежние пропорции по серединам диапазонов: 27,5 г белка и 15,5 г жира при 277,5 ккал. По формуле 4/9/4 это 39,6% / 50,3% / 10,1% энергии из Б / Ж / У. Это **не назначенные FEDIAF/NRC нормы БЖУ** и не проверка полноценности.
- Новые диапазоны Б/Ж масштабированы одним коэффициентом 320 / 277,5 и округлены до целых: 25–38 и 10–25 г. Углеводы рассчитаны в профиле по остатку энергии, но их обязательный минимум в рецепте не вводится.
- В таблице профиля: ориентир всего дня, ориентир домашней доли, фактически введённый сухой корм и весь фактический день (с текущим рецептом). Если БЖУ сухого корма неизвестны, соответствующие клетки остаются прочерками.
- Цель 310–330 ккал — около 42% MER при k=110. Доля 50% в профиле — около 381 ккал. Приложение показывает различие; кнопка применения профиля меняет цели только по вашему действию.

Источники: [FEDIAF 2025, VII-6 и VII-7](https://europeanpetfood.org/wp-content/uploads/2025/09/FEDIAF-Nutritional-Guidelines_2025-ONLINE.pdf#page=54), [NRC 2006](https://nap.nationalacademies.org/catalog/10668/nutrient-requirements-of-dogs-and-cats), [WSAVA, таблица NRC](https://wsava.org/wp-content/uploads/2020/07/Calorie-Needs-for-Healthy-Adult-Dogs-updated-July-2020.pdf).

## Сувид

Ручной выбор толщины убран. Все текущие рекомендации и PDF рассчитаны на слой **2–3 см** охлаждённых продуктов; для промежуточной толщины выбирайте время 3 см. Поля толщины в старых рецептах принимаются для совместимости, но текущие рекомендации их не используют.

За основу взята кулинарная таблица пользователя. Бескостное бедро птицы: 73 °C / 60 минут кусочками или 90 минут цельным филе, с контролем центра ≥70 °C не менее 2 минут. Индюшиная грудка: 65 °C / 2 часа. Куриная грудка: 65 °C / 60 минут для 2 см, 75 минут для 3 см. Утиная грудка: 58 °C / 2 часа для 2 см, 2 часа 45 минут для 3 см — исходный час увеличен по таблице птицы Baldwin. Свиная вырезка: 65 °C / 2 часа. Говяжья вырезка: 62 °C / 2 часа. Голяшка: 85 °C / ориентировочно 6–8 часов для бескостных кусочков 1,5–2 см, нарезанных поперёк волокон, в пакете слоем 2–3 см. После 6 часов проверить, легко ли мясо режется вилкой и нет ли резиновых тяжей; при необходимости продолжить на 1–2 часа. Это согласованный пробный ориентир по текстуре, а не измерение усвоения коллагена или валидация срока хранения. Для лопатки сохранён отдельный длительный режим на мягкость. Режимы для костей, маринадов с луком и копчения не перенесены.

Рыба: **55 °C**, с полным временем прогрева и пастеризации по Baldwin 3.1. Жирная: 2 см — 4 ч 45 мин; 3 см — 5 ч 15 мин. Нежирная: 2 см — 3 ч; 3 см — 3 ч 45 мин. Рядом дана альтернатива **58 °C** с меньшим временем. Кулинарный режим 52–55 °C / 30 минут не обозначается как пастеризация для хранения. Для конкретного вида рыбы справочная категория — ориентир, а не валидация процесса.

Овощи: тыква — 85 °C / около 60 минут; бруснику (свежую или предварительно размороженную) можно готовить с ней в одном пакете, сок идёт в корм. Морковь и батат — 85 °C / 60–90 минут до полной готовности и мягкости; можно подавать небольшими кусочками, разминать необязательно. Кабачок, брокколи и другие нежные овощи — 85 °C / 30–60 минут, цветная капуста — 85 °C / 45–60 минут. Проверять мягкость; время зависит от нарезки и сорта.

Клубника: вымыть, убрать зелёные чашелистики, нарезать, добавить свежей перед подачей. Голубика: вымыть, крупные ягоды разрезать. Яблоко и груша: вымыть, удалить сердцевину с семенами, нарезать небольшими кусочками; 85 °C / ориентировочно 45–60 минут до мягкости. Малина: свежую перебрать и аккуратно промыть, замороженную разморозить в холодильнике; 85 °C / ориентировочно 30–60 минут, можно с тыквой около 60 минут. Ягоды разварятся, сок идёт в корм. Удаление сердцевины и семян относится только к яблоку и груше. Свежую клубнику и голубику не добавлять в закрываемые на хранение готовые заготовки; смешивать перед кормлением. Масло — в готовую порцию.

Быстро охладить в закрытом пакете в ледяной воде, проверить центр ≤3 °C. На ближайшие 2–3 дня — 0…+2 °C, остальные порции заморозить. Срок две недели в домашнем холодильнике не подтверждён. Время отсчитывается после восстановления температуры ванны; пакеты погружены, между ними циркулирует вода. Пастеризация не уничтожает все споры. КБЖУ не определяют полноценность по минералам и витаминам.

Источники: [Baldwin, таблицы 3.1, 4.1, 5.1](https://douglasbaldwin.com/sous-vide.html), [FSA, контроль температуры центра](https://www.food.gov.uk/safety-hygiene/cooking-your-food), [Baldwin, CRC Handbook](https://douglasbaldwin.com/media/Sous_Vide_Cooking_for_CRC_Handbook.pdf), [Zwilling, тыква](https://www.zwilling.com/us/sous-vide-recipes/pumpkin-vegetables-sous-vide.html). Предоставленная пользователем кулинарная таблица не содержит автора и условий валидации; это отмечено в интерфейсе.

## Восстановление пароля письмом

Регистрация — по email и паролю. «Забыли пароль?» отправляет одноразовую ссылку на 30 минут; по ней пользователь задаёт и повторяет новый пароль, затем входит. Старые сеансы завершаются; рецепты остаются в аккаунте. Код восстановления больше не выдаётся.

После регистрации приходит отдельное письмо подтверждения (ссылка на 24 часа). Восстановление доступно и при пропущенном письме подтверждения: успешный сброс пароля сам подтверждает владение адресом. Для старых аккаунтов вход по прежнему логину сохранён; кнопка «Подтвердить почту» позволяет привязать email с текущим паролем и подтверждением в письме. Старый аккаунт и рецепты не создаются заново.

[Настройка почты на хостинге](EMAIL-SETUP.md). Из GitHub письма не отправляются; требуется установленный PHP API и настроенный почтовый транспорт хостинга.

## Автоматические БЖ при правке калорий

Правка любой границы калорийности заново подставляет диапазоны белка и жира по середине нового диапазона и прежним пропорциям (база 277,5 ккал, Б 22–33 г, Ж 9–22 г). Все цели округляются до целых. Белок и жир можно вручную изменить; эти правки сохраняются до следующего изменения калорий. Углеводы не меняются. Если граница калорий пуста или минимум больше максимума, новые БЖ не подставляются до исправления диапазона.

Проверки обновления 8: автоподстановка и округление БЖ, ручное редактирование с перезагрузкой, пустые и перевёрнутые границы калорий, 46 маршрутов приготовления, совместимость прежней толщины в сохранённых файлах, PDF, семь ширин экрана и регрессия сохранения/автоподбора.
