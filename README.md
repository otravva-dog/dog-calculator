# Конструктор питания 🐾

Компактный калькулятор и библиотека рецептов для домашней части кормления.

## Открыть без установки

Скачайте [`calculator.html`](https://github.com/otravva-dog/dog-calculator/blob/main/calculator.html) кнопкой **Download raw file** и откройте в браузере. В него встроены Manrope, стили и логика. В автономном режиме рецепты хранятся на устройстве.

**PDF:** кнопка «📄 PDF» → в диалоге печати выбрать «Сохранить как PDF». В документ входят эмодзи, граммовки на порцию и партию, КБЖУ и режимы приготовления.

## Запуск на gavstronomiya.ru / REG.RU

Нужен именно **веб-хостинг с PHP 8.1+ и PDO_SQLITE**, а не только регистрация домена. В REG.RU: «Мои услуги» → «Хостинг» → активная услуга → панель управления. Наличие купленного домена не означает наличие хостинга. PHP на тарифе Host-Lite может быть недоступен: [справка REG.RU](https://help.reg.ru/support/hosting/php-asp-net-i-skripty/kak-smenit-versiyu-php-na-hostinge).

1. Сделайте резервную копию действующего сайта.
2. В панели хостинга включите PHP 8.1 или новее и HTTPS. Проверьте расширение **pdo_sqlite**.
3. Скачайте проект через **Code → Download ZIP**. Распакуйте.
4. Скопируйте **содержимое** проекта в корневую папку нужного сайта (имя папки уточняется в панели). Нужны `index.html`, `styles.css`, `script.js`, `fonts/`, `api/`. Не загружайте данные рабочих пользователей в GitHub.
5. Откройте `https://www.gavstronomiya.ru/`. При наличии серверного API появится кнопка **«Войти»**.
6. Зарегистрируйтесь: логин и пароль от 12 символов. Скачайте личный код восстановления. На другом устройстве войдите с тем же логином.

Если в корне уже размещён другой сайт, установите калькулятор в отдельную папку, например `nutrition/`, сохранив структуру файлов. API определяется относительно папки калькулятора. Не заменяйте действующую главную страницу без необходимости.

В REG.RU нет автоматически подключённого доступа из этого чата. Изменение файлов в GitHub само по себе не размещает их на REG.RU, если у вас не настроено отдельное развёртывание. Эта версия подготовлена для установки, её размещение на домене пока не подтверждено.

## Серверные рецепты

- Сессии с защищёнными HttpOnly/SameSite cookies; запросы записи защищены CSRF-токеном и проверкой Origin.
- Сервер авторизует каждый рецепт по владельцу. Два устройства видят одну библиотеку после входа и синхронизации.
- «Обновить» изменяет открытый рецепт; «Копия» создаёт новый.
- Конфликт правок с двух устройств не перезаписывает свежую версию. Нажмите «Синхронизировать», откройте актуальный рецепт или сохраните копию.
- Создание нового рецепта и изменения черновика не отправляются в облако до нажатия «Сохранить».
- Ранее локальные рецепты: откройте каждый и нажмите «Сохранить» после входа. JSON-экспорт — резервная копия, PDF — удобный документ, не формат импорта.
- До 500 рецептов на пользователя. Восстановление пароля — по скачанному коду; после восстановления прежние сессии отзываются. Код никому не передавайте.
- SQLite и PHP-сессии создаются в закрытой папке **выше корня сайта**, с запретом использования папки внутри DocumentRoot. Резервируйте эту папку отдельно от кода.
- По умолчанию приватная папка: родитель папки сайта + `nutrition-private-<хеш>`. Если ограничения хостинга не дают её создать, задайте `NUTRITION_DATA_DIR` в окружении PHP: существующий закрытый путь вне корня сайта с правами записи. Не помещайте базу в `public_html`, `www`, `htdocs` или GitHub.
- Не используйте один логин для разных людей. Не храните код восстановления в публичном репозитории. Срок сессии — до 30 дней, с выходом после 7 дней бездействия.

## Изменения

- Manrope и название «Конструктор питания».
- Цели в одну строку на компьютере; состав и итог — вертикально, с компактными строками.
- Цели по умолчанию: 270–285 ккал, белок 22–33 г, жир 9–22 г. Углеводы без обязательного минимума.
- Вес сырого съедобного продукта. Шаг продуктов 5 г; масла 1 г. При завершении ручного ввода значение приводится к шагу. Закреплённые строки не меняются подбором.
- Название автоматически: основной белок + овощ с наибольшим весом (повторные строки суммируются). Его можно изменить вручную.
- Творог удалён. Исходный справочник сохранён; дополнительные продукты — ориентировочные значения.
- КБЖУ на 100 г редактируются отдельно от граммов. Калории не заменяются автоматически формулой 4/9/4.

## Сувид

План зависит от выбранных продуктов и слоя 1 / 1,5 / 2 см. Разные режимы — отдельные пакеты. Слой измеряется в самом толстом месте; продукты охлаждённые, не замороженные. Время отсчитывается после восстановления температуры ванны.

Рыба: таблица Baldwin 3.1; птица: 4.1; говядина, свинина, баранина: 5.1. В режиме 65 °C для обычного мяса/птицы выбран час, не меньше табличного минимума для предложенной толщины. Для голяшки выбран **80 °C / 16 ч** на мягкость; лопатки — **80 °C / 12 ч**. Овощные режимы — кулинарные ориентиры до мягкости, не подтверждение срока хранения. Кролик требует контроля температуры центра ≥74 °C. Фрукты/ягоды предлагаются свежими перед подачей, не как пастеризованная часть заготовки.

**55 °C / 30 минут для сёмги не обозначается как пастеризация.** Для слоя до 1 см выбран табличный режим **60 °C / 50 минут**. Для двухнедельной партии предусмотрите замораживание после быстрого охлаждения; две недели в холодильнике не подтверждены.

КБЖУ не определяют полноценность по минералам и витаминам. При 50% домашних калорий нужен расчёт всего дня с учётом корма и добавок.

Источники: [Baldwin, Practical Guide](https://douglasbaldwin.com/sous-vide.html), [Baldwin, CRC Handbook](https://douglasbaldwin.com/media/Sous_Vide_Cooking_for_CRC_Handbook.pdf), [Zwilling, тыква](https://www.zwilling.com/us/sous-vide-recipes/pumpkin-vegetables-sous-vide.html), [Wolf, овощи](https://au.subzero-wolf.com/-/media/files/united-states/product-downloads/icb-sub-zero-wolf/wolf/ebooks/convection-steam-oven---technique-and-recipe-guide.pdf).

## Проверки

В Chromium проверены мобильная и настольная вёрстка, загрузка Manrope, шаги веса, закрепление, подбор, обновление/копия, печатный PDF и смена режимов сувида. На локальном PHP 8.4 + SQLite проверены регистрация, два независимых браузера, синхронизация, изоляция пользователей, CSRF, конфликты версий, восстановление и отзыв сессий. Производственный хостинг REG.RU пока не проверен.
