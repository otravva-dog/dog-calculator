# Вечерняя порция

## Как открыть калькулятор

1. Откройте [calculator.html](https://github.com/otravva-dog/dog-calculator/blob/main/calculator.html).
2. Нажмите **Download raw file** — значок скачивания над кодом справа.
3. Откройте скачанный HTML в браузере. Всё необходимое встроено, установка не нужна.

Весь проект: **Code → Download ZIP**, распакуйте и откройте `calculator.html`.

Для размещения на сайте: `index.html`, `styles.css`, `script.js` в одной папке. Старый `style.css` новой страницей не используется.

## Возможности и ограничения

Вечерняя порция — обновлённый калькулятор

Откройте calculator.html: он содержит CSS и JS внутри и работает без установки.
Для размещения на своём сайте используйте index.html, styles.css, script.js рядом.

Цели по умолчанию: 270–285 ккал, 20–25 г белка, 8–12 г жира.
Творог полностью удалён. Справочник исходных продуктов сохранён, новые продукты — ориентировочные значения.
Все граммовки — сырые съедобные продукты. Масло — в граммах.
Ручная правка не изменяет другие строки. Автоподбор меняет только незакреплённые строки.
Автоподбор приближённый: проверяйте отклонения после округления.
Рецепты сохраняются в браузере; делайте экспорт JSON. Старые записи исходного калькулятора автоматически не переносятся.

Профиль даёт ориентир калорий для здоровой взрослой собаки, а не назначение диеты.
Калькулятор не проверяет минеральную и витаминную полноценность.
Рекомендации по сувиду не заменяют проверенную таблицу пастеризации для вашего продукта и толщины.
Две недели хранения в холодильнике не подтверждены. Для партии на 2 недели предусмотрите замораживание.

Проверки: синтаксис JS; автоподбор, закрепление и пустой состав; Chromium — мобильная/настольная ширина, добавление строки, подбор, сохранение и восстановление, безопасное отображение названия.
