# Проверка выпуска

PHP 8.1+ с PDO MySQL / PDO SQLite, Node.js и Python 3 для сборки. В браузерном тесте используется Playwright; браузер устанавливается отдельно.

```sh
npm ci
npm test
python3 tools/build.py
npx playwright install chromium
npm run test:browser
```

Для системного Chromium задайте `CHROMIUM_PATH=/usr/bin/chromium`. `NUTRITION_ARTIFACT_DIR` задаёт папку PDF и снимков. Браузерная проверка проверяет пользовательское название, мобильные ширины, геометрию двух половин A4, длинные рецепты без потери граммов, размеры наклеек и автономную страницу.

## MySQL

Создайте отдельную пустую базу с именем, заканчивающимся `_test`, и конфигурацию вне корня сайта. Тест откажется работать при наличии аккаунтов. Он создаёт только синтетические записи; после проверки тестовую базу можно удалить.

```sh
NUTRITION_TESTING=1 php tests/mysql-smoke.php --private=/ABSOLUTE/TEST_PRIVATE
```

Проверяются исходная SQLite без записи, ID и хэши, ревизии, повторный импорт, версии рецепта, отдельные собаки, идемпотентный каталог, единицы нутриентов и журнал.
