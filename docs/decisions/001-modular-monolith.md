# 001 · Одно приложение и одна MySQL

Принято пользователем 23.11.2026. Открытый сервис, несколько собак в аккаунте. Сохраняем PHP и обычный JS; границы модулей задаются прикладными контрактами и хранилищем. Пользовательские данные, общий каталог и журнал разделены таблицами, правами и кодом.

Сначала выпускается совместимая версия с явным переносом. Действующая SQLite не удаляется и не заменяется пустой базой при сбое MySQL. Каталог пока редактируется в GitHub; будущая админка получает отдельный доступ и историю изменений.

Переход на MySQL — отдельное переключение конфигурации после резервной копии, проверки и короткой паузы записи. Для импорта используется отдельный приватный каталог с конфигурацией целевой БД; он не переключает рабочий сайт преждевременно.
