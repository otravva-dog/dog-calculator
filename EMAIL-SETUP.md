# Вход без почты

Начиная с версии 11 почта не используется. Нужны логин и пароль от 4 символов. Настройки отправки писем не требуются; прежние аккаунты и рецепты сохраняются.

Установка и текущие возможности описаны в [README.md](README.md). API использует `api/auth.php`. Старый обработчик `email-auth.php` отключён.
